# Presentation Assets

Each workstream keeps its presentation-ready figures and notes under its own directory:

```text
presentation/
├─ A/
│  ├─ A_baseline_slides.md
│  ├─ A_PR_BODY.md
│  ├─ experiment_notes.md
│  ├─ figures/
│  └─ docs/
└─ B/  # created by the B owner when that workstream is complete
```

Do not mix figures from different configurations or trajectory exporters in the same
comparison slide.
