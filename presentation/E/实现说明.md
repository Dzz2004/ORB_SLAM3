# 质量感知降级与恢复策略

## 实现与接口

E 读取 A PR #2 导出的跟踪状态、跟踪点数、逐帧机体轨迹、深度有效率与 IMU。跟踪点数按 A 的 1250 特征配置归一化，作为视觉质量代理。质量下跌即时生效，回升做平滑。状态机按观测质量进入正常、视觉退化、深度退化、仅 IMU 或恢复确认状态。

- 视觉仍可靠时，深度退化状态保留通过质量门限的 SLAM 位姿。
- RGB 和深度同时退化时，从最近可信状态调用 D PR #1 的 IMU 积分器。联调版使用最近两个已接受位姿差分估速，偏置设为零。最多预测 2 秒，IMU 采样间隔超限或缺少初始速度时暂停预测输出。
- 视觉恢复后检查连续帧的位姿一致性。当前默认连续 3 帧通过检查且满足最短状态保持时间后恢复发布 SLAM 位姿。

阈值和运行配置见 [config.json](../../experiments/E_adaptive_recovery/config.json)。模块实现与复现说明见 [E 实验目录](../../experiments/E_adaptive_recovery/)。

## 3.6 汇报结果

使用 TartanAir V2 OldTownSummer easy/P000 的 RGB-D+IMU 实测日志。每个种子取 23.0–29.9 秒的 70 帧，25.0–27.0 秒为屏蔽窗。正常输入和三种故障条件各跑三组策略、三个种子，共 36 组离线回放。故障窗后恢复原始日志，恢复时间衡量策略确认延迟。

| 双中断条件 | 原始基线 | 仅质量监控 | 质量监控 + IMU |
| --- | ---: | ---: | ---: |
| 位姿输出覆盖率 | 71.4% | 68.6% | 97.1% |
| 正常帧准确率 | 100% | 96% | 96% |
| 错误接管帧数 | 0 | 0 | 0 |
| 预测覆盖时间 | 0 s | 0 s | 2.0 s |
| 恢复确认时间 | 0.2 s | 0.4 s | 0.4 s |

预测满 2 秒时，三个种子的位置误差为 0.365、0.849、0.834 米，姿态误差为 0.202°、0.206°、0.213°。只有一个种子同时达到 0.5 米和 5° 的阈值。三个种子共享一份 IMU 记录，起始位姿和估计速度来自各自的 SLAM 运行。双中断故障窗内主动屏蔽了 SLAM 位姿，错误接管 0 帧只反映本场景。

## 复现

从仓库根目录执行以下命令。数据和新结果写到仓库外。

```bash
python -m pip install -r experiments/E_adaptive_recovery/requirements.txt
python -m unittest discover -s experiments/E_adaptive_recovery -v
python experiments/E_adaptive_recovery/replay_a_d.py --download --raw ../E-a-inputs --cases ../E-a-cases --out ../E-a-d-results
```

逐帧状态、各组指标和输入版本见 [policy_events.csv](../../results/E/a_d_offline/policy_events.csv)、[ablation.csv](../../results/E/a_d_offline/ablation.csv) 和 [metrics.json](../../results/E/a_d_offline/metrics.json)。汇报数字与图表为离线策略验证结果，传感器故障下的 SLAM 重定位耗时尚未测量。
